# 내 사업과 투자의 '진짜 신호'를 찾는 가장 빠른 방법, Daily Signal Editor

AI와 비즈니스 뉴스, 매일 쏟아지는 정보 속에서 나에게 진짜 필요한 내용을 찾기 힘드셨나요?

Daily Signal Editor는 단순한 뉴스 요약 도구가 아니에요. 수많은 정보 중 **내 사업과 투자의 '진짜 신호'만 골라내고**, 바로 실행에 옮길 수 있는 인사이트와 초안까지 만들어주는 나만의 **전략 리서치 팀**입니다.

## 정보 요약을 넘어, 실행을 위한 인사이트까지

```text
믿을 만한 소스 -> 중요한 신호 선별 -> 패턴 합성 -> 내 목적에 맞는 실행 산출물
```

Daily Signal Editor는 공개 소스, RSS, 리포트 링크, 사용자가 제공한 URL, 또는 mock data를 바탕으로 다음 일을 합니다.

- 비즈니스/AI/투자/스타트업 관련 후보 소스를 정리합니다.
- 후보 아이템을 신선도, 출처 신뢰도, 사용자 적합도, 사업적 영향, 독창성, 콘텐츠 잠재력으로 점수화합니다.
- 상위 신호 3-7개를 골라 "무슨 일이 있었는지"보다 "왜 중요한지"를 설명합니다.
- 여러 신호를 연결해 "지금 시장이 어느 방향으로 움직이는지"를 합성합니다.
- 브리프, 뉴스레터 초안, 콘텐츠 앵글, 리서치 메모, Slack 팀 업데이트, 전략 회의 안건 형태로 바꿉니다.
- 출처 링크, 저작권, paywall, 투자 조언 리스크를 함께 확인합니다.

## 매일 쏟아지는 정보, 정작 내 사업에 쓸 건 없나요?

정보가 부족해서가 아니라, **정리할 시간이 부족해서** 놓치는 기회가 너무 많으니까요.

- 수많은 소스 중 무엇을 먼저 읽을지 고민하는 시간
- 수많은 글 중 나에게 중요한 내용만 골라내는 번거로움
- 단순 요약을 넘어 비즈니스적 의미를 해석하는 과정
- 이걸 다시 뉴스레터, 블로그, 투자 메모로 옮겨 적는 일

Daily Signal Editor가 이 모든 반복적인 업무를 대신해 드릴게요. 여러분은 결정에만 집중하세요.

## 이런 고민을 하고 있다면 지금 바로 시작하세요

| 누가 쓰면 좋나요? | 이런 고민이 있다면 | 이렇게 해결해 드려요 |
| --- | --- | --- |
| 창업자 | 시장 변화, 고객 pain, AI 제품 기회를 빨리 파악하고 싶다 | 사업 기회 브리프, 제품 아이디어, 피치 앵글 |
| B2B 마케터 | 매주 쓸 만한 thought leadership 주제가 필요하다 | 뉴스레터 초안, 블로그 아웃라인, 링크드인 포스트 |
| 투자자/애널리스트 | 섹터별 narrative와 공개 근거를 정리하고 싶다 | 출처 기반 리서치 메모, watchlist theme |
| 사내 전략 기획자 | 경쟁사/기술/시장 리스크를 팀에 공유해야 한다 | 전략 회의 안건, 리스크 메모, Slack 업데이트 |
| B2B 세일즈 | 고객이 관심 가질 산업 변화와 대화 소재가 필요하다 | 계정별 대화 포인트, 아웃리치 훅 |
| 취준생/이직러 | 산업 이해와 면접용 관점을 빠르게 쌓고 싶다 | 산업 브리프, 면접 질문, 회사별 리서치 |
| 크리에이터 | 사람들이 필요로 하는 유익하고 재밌는 콘텐츠를 빨리 만들고 싶다 | 콘텐츠 후보, 제목, 훅, 긴 글 구조 |
| 바쁜 직장인 | 내 분야의 중요한 변화만 놓치지 않고 싶다 | 개인 맞춤 daily brief |

## 이럴 때 사용하면 가장 효과적이에요

- "오늘 AI/비즈니스/투자에서 중요한 것만 골라줘"
- "YC, a16z, GeekNews, 한국 스타트업 뉴스를 보고 창업자 관점 브리프를 만들어줘"
- "이번 주 뉴스레터에 쓸 만한 B2B SaaS 글감 찾아줘"
- "AI 인프라 섹터 리서치 메모 초안 만들어줘"
- "부자 리포트와 VC 콘텐츠를 참고해서 콘텐츠 앵글을 뽑아줘"
- "이번 주 전략 회의에 올릴 AI 경쟁사/시장 안건을 만들어줘"
- "B2B 영업팀이 고객에게 보낼 산업 변화 Slack 업데이트를 만들어줘"

## 이런 경우에는 사용을 권장하지 않아요

- 유료 뉴스레터나 로그인이 필요한 사이트의 전체 내용을 볼 때
- 주식 매수/매도 추천이나 수익 보장이 필요할 때 (투자 조언이 아닌 리서치 목적이에요)
- 출처 없는 루머를 사실처럼 정리해야 할 때
- 개인정보나 내부 기밀 자료를 다뤄야 할 때

## 정보가 돈과 전략이 되는 순간들

이 Skill을 쓰면 단순 요약이 아니라 아래 결과물을 만들 수 있습니다.

- 매일 아침 읽는 개인 맞춤 시장 브리프.
- "오늘의 중요한 AI/비즈니스/투자 신호 5개".
- 창업자 관점의 제품/시장 기회 메모.
- B2B 마케팅용 뉴스레터 초안.
- 링크드인/X 포스트 훅과 근거.
- 긴 글/블로그/리포트 아웃라인.
- 투자 리서치용 watchlist theme.
- 한국 시장에 맞춘 글로벌 VC 글 해석.
- 사내 공유용 Slack 업데이트.
- 주간 전략 회의 안건.
- 고객 미팅 전 B2B 세일즈 대화 포인트.

## 더 정확한 결과를 위해 필요한 정보들

| 입력 | 설명 | 예시 |
| --- | --- | --- |
| `audience` | 누구를 위한 결과물인가 | `Korean B2B SaaS founder` |
| `purpose` | 왜 읽는가 | `weekly newsletter`, `market research`, `investment research` |
| `domains` | 관심 주제 | `AI agents`, `VC`, `Korea startups` |
| `source_mix` | 어떤 소스 묶음을 볼 것인가 | `global VC`, `Korea startup`, `market reports` |
| `output_mode` | 어떤 결과물을 만들 것인가 | `daily brief`, `newsletter draft`, `research memo` |
| `time_window` | 어느 기간을 볼 것인가 | `today`, `last 24 hours`, `this week` |
| `lens_team` | 어떤 전문가 렌즈를 활성화할 것인가 | `founder`, `ai workflow`, `korea business`, `content` |

## 실제로 이런 결과물을 받을 수 있어요

생성 예시는 [examples/daily-brief.md](examples/daily-brief.md)에 있습니다.

출력은 이런 구조입니다.

```md
# Daily Signal Brief

## Executive Read
오늘 가장 중요한 변화의 한 줄 요약

## Top Signals
### 1. 신호 제목
- Source: 출처 링크
- Score: 4.7 / 5
- What happened: 무슨 일이 있었나
- Why it matters: 왜 중요한가
- Who cares: 누구에게 중요한가
- What to watch: 다음에 확인할 것
- Content angle: 콘텐츠로 만들 때의 앵글

## Content Starters
바로 글로 바꿀 수 있는 훅과 근거

## Pattern Synthesis
신호들을 종합했을 때 보이는 시장 방향

## Actionable Artifacts
Slack 업데이트, 링크드인 훅, 전략 회의 안건 등

## Caveats
출처/저작권/투자 조언 관련 주의사항
```

## 왜 이 스킬이 비즈니스에서 가치 있나요?

이 Skill은 "나만을 위한 뉴스레터"에 머물지 않습니다. 반복 업무가 명확한 여러 시장으로 바꿔 쓸 수 있습니다.

### 1. B2B 콘텐츠 팀

B2B 팀은 매주 신뢰할 만한 관점이 담긴 콘텐츠를 만들어야 합니다. 하지만 좋은 주제를 찾고, 근거를 모으고, 글의 앵글을 잡는 시간이 오래 걸립니다. 이 Skill은 리서치와 초안 사이의 시간을 줄입니다.

### 2. 창업자와 빌더

창업자는 매일 시장과 기술의 변화를 봐야 하지만, 모든 글을 읽을 수 없습니다. 이 Skill은 "무엇이 바뀌고 있고, 내 제품이나 고객에게 어떤 의미가 있는지"를 중심으로 정리합니다.

### 3. 투자자와 애널리스트

투자 관련 정보는 출처와 표현이 중요합니다. 이 Skill은 공개 정보 기반 리서치로 제한하고, 매수/매도 추천이 아니라 theme, evidence, watch question을 남기도록 설계되어 있습니다.

### 4. 전문 크리에이터

크리에이터에게 필요한 것은 단순 요약이 아니라 "사람들이 읽고 싶어 하는 관점"입니다. 이 Skill은 유익하고 재밌는 콘텐츠 후보를 뽑고, 제목과 훅까지 이어줍니다.

## 안전하고 투명한 결과물을 약속합니다

- 모든 핵심 신호에는 믿을 수 있는 **출처 링크**를 꼭 붙여요.
- 저작권을 존중하며 기사나 리포트의 본문 전체를 무단으로 복사하지 않아요.
- 유료/로그인 기반 정보는 사용자가 직접 제공하거나 공개된 정보 안에서만 정리해요.
- 투자 관련 결과물은 리서치와 교육 목적으로만 작성하며, 특정 종목 추천은 하지 않아요.
- 글로벌 소식을 전할 때는 한국 시장의 특수한 맥락(규제, 문화 등)을 함께 고려해요.

## 1분 만에 데모 실행해보기

mock data로 데일리 브리프를 생성합니다.

```bash
python3 scripts/build_digest.py \
  --sources mock-data/sample-sources.json \
  --items mock-data/sample-items.json \
  --profile mock-data/sample-user-profile.json \
  --output examples/daily-brief.md
```

검증합니다.

```bash
python3 scripts/validate_digest.py examples/daily-brief.md
```

아이템 점수를 JSON으로 확인합니다.

```bash
python3 scripts/score_items.py \
  --sources mock-data/sample-sources.json \
  --items mock-data/sample-items.json \
  --profile mock-data/sample-user-profile.json
```

공개 RSS 소스로 live item을 가져와 테스트합니다. 기본 live demo는 현재 접근 가능한 RSS만 포함합니다. a16z처럼 feed 경로가 바뀌거나 404를 반환하는 소스는 [references/source-catalog.md](references/source-catalog.md)에 후보로 두고, 검증된 feed URL이 있을 때 live source에 추가합니다.

```bash
python3 scripts/fetch_rss.py \
  --sources mock-data/live-sources.json \
  --output /tmp/daily-signal-live-items.json \
  --max-items-per-source 3

python3 scripts/build_digest.py \
  --sources mock-data/live-sources.json \
  --items /tmp/daily-signal-live-items.json \
  --profile mock-data/profiles/founder.json \
  --output /tmp/daily-signal-live-founder-brief.md
```

## 높은 퀄리티를 유지하기 위한 기준

단순한 요약기가 아니라, 실제로 도움이 되는 리서치 파트너가 되기 위해 노력해요.

- 소스를 고르고 분류하는 수고를 덜어드려요.
- 모든 정보의 근거와 링크를 투명하게 보존해요.
- 각 사용자에게 왜 중요한 정보인지 맞춤형으로 설명해요.
- 브리프부터 뉴스레터, SNS 포스트까지 즉시 활용 가능한 결과물을 만들어요.
- 근거가 부족할 때는 "충분한 근거가 없다"고 솔직하게 말씀드려요.
